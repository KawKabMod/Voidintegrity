## Overview

Play Integrity Fix KeyBox is designed to provide a consistent and reliable solution for passing Play Integrity checks across a wide range of Android devices.

The project focuses on stability, minimal configuration, and long-term maintainability.

---

## Features

- Strong Integrity support  
- Device & Basic Integrity compatibility  
- Wide Android support (8 – 16)  
- Clean and minimal setup  
- Optimized for stability and performance  

---

## Installation

1. Download the latest release  
2. Flash via Magisk / KernelSU / APatch  
3. Reboot  
4. Verify integrity status
